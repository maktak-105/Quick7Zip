# タイトルバーのダークモード対応

## ユーザー指示（原文・2026-09-21）
- 「Quick7Zipがダークモードになり切れていない、メニューバーの上、なんていうんだっけ、Xとか_のバーが明るいまま」

## ユーザー指示 2（原文・2026-09-21、調査の途中で追加）
- 「QuickMarkPDFも」
- 「暗くなっていない」
- 同じ症状が QuickMarkPDF にもある。対象を Quick7Zip と QuickMarkPDF の 2 つにする（QuickMarkPDF 側の記録は、QuickMarkPDF の `plans/2026-09-21_タイトルバーのダークモード_v1.0.md`）。

## 解釈
- 「メニューバーの上の、×や _ があるバー」は、ウィンドウのタイトルバー（キャプションバー。最小化・最大化・閉じるのボタンがある帯）のこと。アプリの中身（HTML の UI）はダークだが、タイトルバーが Windows 標準の明るい色のまま、と読む。
- Quick シリーズの共通仕様（ダークテーマ。QuickImageView ではタイトルバーを含めてダーク）に合わせて、Quick7Zip のタイトルバーをダークにする。

## 調査項目
1. Quick7Zip のウィンドウの作り方（`src/app/main_gui.cpp` の `CreateWindowExW`）と、現在のダーク対応の有無。
2. 他に明るいままの部分が無いか（他のトップレベルウィンドウ、ウィンドウの背景色、起動直後のちらつき）。
3. 共通テンプレートと、QuickImageView の実装（`window_theme.cpp`）の方式。
4. 修正、ビルド、テスト、可能な範囲での実物確認（DWM の属性の読み戻し）。

## 結果（2026-09-21）
- 原因: `CreateWindowExW` の後に、ダークモード（`DwmSetWindowAttribute`）を有効にする処理が無かった。
- 修正: `src/app/main_gui.cpp` に `ApplyDarkTitleBar()` を追加し、ウィンドウ作成の直後に呼ぶ（`dwmapi.dll` は実行時に参照。リンク設定の変更なし）。
- ビルド: 成功（27 秒）。出力は `dist\Quick7Zip.exe`。
- 実物確認: 修正前の exe は属性 0（明るい）、新 exe は属性 1。`PrintWindow` でのタイトルバーの平均色は輝度 34（暗い）。画像で、暗いグレーに白い文字を確認。画面操作なし。
- 未実施: コミット・push・リリース（指示なし）。

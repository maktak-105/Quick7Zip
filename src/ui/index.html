Quick7Zipの使い方

        
      

      
    
        
  1. 圧縮したいフォルダ／ドライブと、出力する.7zファイルを指定します。
    2. 
        
  2. 自動分析された設定(圧縮レベル・スレッド数など)を確認します。
    3. 
        
  3. 必要に応じてAES-256暗号化・分割ボリュームを設定します。
    4. 
        
  4. 「圧縮を開始」を押すと7-Zipが実行されます。
    5.
